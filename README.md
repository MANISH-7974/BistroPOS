# BistroPOS - Enterprise Web POS Terminal
A modern, 3-tier Point of Sale web application developed for Milestone 3. 

## Features
* **Glassmorphism UI:** Modern, responsive frontend built with Bootstrap 5, custom CSS physics, and Lucide vector icons.
* **Dynamic Cart Logic:** Real-time JavaScript cart calculations including GST slabs and percentage discounts.
* **Python/Flask Backend:** Secure routing and automated Token Number generation.
* **PDF Invoice Engine:** Auto-generates and downloads formatted A5 PDF receipts using `fpdf`.
* **Flat-File Database:** Lightweight `csv` persistence for daily sales logs.
